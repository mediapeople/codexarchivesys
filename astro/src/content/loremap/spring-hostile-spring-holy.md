structure  

easy now

hand on the cart

teeth

pain

and the spawn  
still need to survive  

with an attitude

if I forget  
for one second  

it all disappears  

this shell included  

but it doesn’t

is back  

same heat  
different pass

pattern resumes  

and the field  
does not resolve

and exits

to show up

when thrown—  

answered  

not with escape  

but with pattern

a node

every scale

and again

and carry  

not transcendence  

but contact  

not escape
