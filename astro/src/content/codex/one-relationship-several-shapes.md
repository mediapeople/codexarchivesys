# One Relationship, Several Shapes

A card, a button, a form, a confirmation, a stored record, a capacity rule, and a cancellation message can look like separate features.

They are often designed that way.

One screen at a time.

One component at a time.

One ticket at a time.

But the person using them does not experience seven features.

They experience one relationship.

Imagine a simple reservation.

There is a person, an event, a place, and a promise that a place will remain available for that person under certain conditions.

That relationship takes several shapes.

**Narrative:** what is being promised.

**Human:** what someone encounters and understands.

**Behavior:** which actions change the relationship.

**Machine:** what must persist and remain true.

The event card introduces the possibility.

The button offers an action.

The form gathers what the relationship requires.

The confirmation states what has changed.

The stored record carries the change forward.

The capacity rule protects the promise from becoming impossible.

The cancellation message explains how the relationship ends.

These surfaces do not need to look identical.

They do need to tell the same truth.

Drift begins when each shape is treated as its own small world.

The button says a place is saved. The confirmation says the request is merely received. The stored record is missing. The capacity rule admits one person too many. The cancellation disappears from the interface but leaves the obligation alive somewhere else.

Every part may be functioning according to its local specification.

The relationship is still broken.

Visual consistency cannot repair semantic disagreement.

A shared color, radius, type scale, and component library can make the system appear coherent while its promises contradict one another underneath.

The deeper design system is the authored relationship.

When its rules change, we should be able to ask which narratives, controls, states, records, and evidence must change with them.

If the event becomes full, what should the card say?

Which action remains available?

What does the person now understand?

What must the machine refuse?

If a reservation is cancelled, which promise ends, which capacity returns, and what evidence remains?

The answers should not be reinvented independently by every surface.

They should be different expressions of the same underlying obligation.

Coherence is not sameness.

It is agreement across shapes.

The work is one agreement rendered many times.
