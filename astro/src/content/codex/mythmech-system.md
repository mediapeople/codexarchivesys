# Mythmech System

Mythmech is a pilot inspection lens for the archive.

It treats an object as authored surface plus structural memory.

That means the object is no longer just readable.
It becomes inspectable, relational, and generative.

This note is a working surface, not a doctrine.
The lens should stay optional, light, and earned by use.

## Core System

- Object = sacred authored content
- Sidecar = structural memory
- Marginalia = lightweight input layer
- Mythmech = inspection lens

## Key Capabilities

- Decompose scrolls into nodes, edges, and load.
- Visualize the tensor of relationships.
- Identify load-bearing lines and mega crystals.
- Enable spawn so parts can become new objects.
- Track lineage as relationships change over time.

## Modes

- `READ` for the normal object.
- `INSPECT` for the structural read.
- `SPAWN` for generating new objects from the inspected parts.

Inspection currently resolves through four passes:

- `WHOLE`
- `LOAD`
- `FAILURE`
- `RECONCILED`

## Sidecar Structure

Mythmech stores four companion layers:

- `mythmech` for nodes, edges, and states
- `lineage` for parents, children, and relations
- `spawn` for candidates and events
- `marginalia` for annotations

## Marginalia Types

- `#seed`
- `#load`
- `#fail`
- `#link`
- `#evol`

## Pipeline

1. Extract nodes from text.
2. Assign load and role.
3. Map relationships.
4. Identify failure.
5. Enable spawn.
6. Track lineage.
